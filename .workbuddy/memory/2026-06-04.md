# 2026-06-04

## 图片转视频 (Image-to-Video)

使用 Agnes Video V2.0 API 将 GitHub 图片生成开挖机场景视频，任务成功完成。

### 关键发现
1. **API Key 是必需的** — 2026-06 起 Agnes API 需要 Bearer token 认证，不再免费无需认证
2. **正确 endpoint**: `https://apihub.agnes-ai.com`
   - `api.agnes.ai` DNS 解析失败
3. **WorkBuddy 临时 Token 无效** — `connect_cloud_service` 获取的 temp token 无法通过 Agnes API 认证
4. **API Key 持久化** — 用户的 API Key 存储在 `~/.workbuddy/skills/agnes-video-2/references/credentials.md`
5. **Poll 间隔** — 视频生成需要较长时间（约 3-5 分钟），poll 间隔 8-15 秒合适，60 次轮询（~8 分钟）通常够用
6. **Image-to-Video 示例**: 使用 GitHub raw URL 作为参考图片成功

### 成功流程
```
图片上传 GitHub → 获取 raw URL → 创建视频任务 (API Key) → 轮询 → 获取视频 URL
```

### 经验教训
- 不要假设 API 免费无需认证，需要验证
- endpoint URL 变更后要同步更新 skill
- API Key 应该持久化在 skill 的 credentials 文件中
