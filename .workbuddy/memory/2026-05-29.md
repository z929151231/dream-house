# 2026-05-29 Game Auto 项目经验总结

## 关键技术经验

1. **大厅卡片识别优化**
   - 初始卡片宽度估算错误(428px)，导致目标游戏《我无限升级》被分割
   - 优化后卡片宽度调整为470px，起始位置180px，提高识别准确率

2. **游戏内交互处理**
   - "高地保安"模式被锁定（需通关难度30）
   - 使用系统返回键退出游戏，避免游戏内返回按钮无效问题
   - 处理确认退出弹窗，点击"退出"按钮而非"取消"

3. **弹窗交互策略**
   - 多次尝试点击取消按钮无效时，及时切换到退出按钮
   - 坐标估算需考虑屏幕分辨率(2340×1080)和实际UI布局

## 问题解决流程

1. **卡片分割问题**
   - 通过分析屏幕布局，调整卡片参数
   - 使用截图分割技术验证坐标计算

2. **游戏内模式限制**
   - 发现模式解锁条件限制
   - 制定替代方案：返回大厅测试其他游戏

3. **退出流程优化**
   - 处理不同类型的确认弹窗
   - 使用系统返回键作为通用退出方案

## 下一步建议

1. 继续探索当前游戏的其他入口（导航栏、右侧菜单）
2. 测试其他游戏卡片，寻找可操作的未锁定游戏
3. 优化多模式交互处理流程

## 经验教训

- 精确的坐标计算是自动化操作的基础
- 游戏内UI元素与系统功能需区分处理
- 多次尝试无效操作时需寻找替代方案
- 退出流程需考虑不同类型的确认弹窗

## ⚠️ 永久禁用操作（用户明确要求）

以下操作已被**永久禁用**，任何情况下不得使用：

| 禁用命令 | 原因 |
|---------|------|
| `pm clear` | 清空APP数据会导致登录状态丢失，危险操作 |
| `am force-stop` | 强制停止应用可能导致状态异常 |
| `adb shell input keyevent 4` | 物理BACK键会触发"确认退出游戏"弹窗 |

**规则**：即使调试失败/状态异常，也**不得使用**上述命令。改用点击方式关闭弹窗或重新定位元素。
